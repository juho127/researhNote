연구노트 스킬(research-note)의 절차를 따라 이 세션의 연구 작업을 기록하세요.

1. `whoami` 로 프로젝트를 확인합니다. 인자 "$ARGUMENTS" 에 프로젝트 ID나 제목 일부가 있으면 그 프로젝트를 고르고, 없으면 대화 맥락으로 고르되 애매하면 사용자에게 물어봅니다.
2. `get_project` 로 현재 단계·최근 기록을 읽어 중복을 피합니다.
3. 대화에서 실제로 수행한 일·결과·다음 할 일·막힌 점을 `## 한 일 / ## 결과 / ## 다음 할 일 / ## 메모` 구조의 마크다운으로 정리해 사용자에게 **먼저 보여주고 확인**을 받은 뒤 `log_progress` 로 저장합니다.
4. 누적 결론이 바뀌었으면 `update_stage`, 다음 할 일은 `add_task` 로 등록합니다.
5. 저장 결과(기록 ID·날짜·단계)를 한 줄로 보고합니다.
